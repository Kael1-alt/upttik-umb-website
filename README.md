# UPTTIK UMB Website (Recreated Template)

Website statis responsif yang dibuat ulang berdasarkan struktur dan informasi publik dari https://upttik-umb.vercel.app/.

## Cara menjalankan
1. Ekstrak folder `upttik-umb-website`.
2. Buka folder tersebut di Visual Studio Code.
3. Buka `index.html` menggunakan browser, atau jalankan dengan ekstensi **Live Server**.

## Struktur
- `index.html` — struktur halaman dan konten.
- `style.css` — desain, layout responsif, tema gelap.
- `script.js` — menu mobile, FAQ accordion, pergantian tema dan bahasa.

## Catatan
- Ini adalah implementasi ulang tampilan/fungsionalitas berdasarkan halaman yang dapat diakses, bukan source code asli dari server.
- Foto hero dan foto bagian Tentang menggunakan URL gambar Unsplash; koneksi internet diperlukan untuk menampilkannya.
- Nomor WhatsApp, alamat, email, dan tautan akademik mengikuti informasi yang ditampilkan pada situs referensi. Pastikan kembali sebelum dipublikasikan.
